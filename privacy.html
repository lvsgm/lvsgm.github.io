プライバシーポリシー

最終更新日: 2026年10月28日

「GMの筋トレ記録 投稿ツール」（以下、本ツール）は、YouTube チャンネル「GMの筋トレ記録」（@gm_workout_log）の運用者が、自分のチャンネルを操作するためだけに使う個人用のツールです。

1. 利用する Google のデータ

本ツールは、運用者本人の Google アカウントで許可した次の権限だけを使います。

  • https://www.googleapis.com/auth/youtube: 自分のチャンネルへの動画のアップロード、タイトル・説明文・タグ・サムネイル・公開日時の設定、自分の動画の一覧と状態の取得
  • https://www.googleapis.com/auth/yt-analytics.readonly: 自分のチャンネルと動画の再生数・視聴時間・登録者の増減などの数字の読み取り

2. データの使い道

取得したデータは、運用者が自分のチャンネルの動画を投稿・管理し、投稿の振り返り（どの動画がよく見られたか）をするためだけに使います。広告、販売、ほかのサービスでの利用、個人の特定には使いません。

3. 保存と管理

  • 認証情報（リフレッシュトークンなど）は、運用者だけが使える実行環境の環境変数に保存し、公開の場所には置きません。
  • Analytics の数字は、運用者の個人用のメモ（Notion など）に、投稿の振り返りのために記録することがあります。
  • ほかの人の Google アカウントのデータは取得・保存しません。

4. 第三者への提供

取得したデータを第三者に販売・提供することはありません。

5. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の利用と他のアプリへの転送は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシー に従います。

6. 許可の取り消し

本ツールへの許可は、Google アカウントの「サードパーティ製のアプリとサービス」 からいつでも取り消せます。
